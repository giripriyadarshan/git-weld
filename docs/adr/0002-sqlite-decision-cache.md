# Store cached decisions in SQLite under the shared Git directory

`git-weld` caches provider decisions in a bundled SQLite database at `<git-common-dir>/git-weld/cache` (opened in WAL mode with a 1-second busy timeout) rather than in `sled` or in a working-tree file. Git and editor integrations can invoke the merge driver from multiple processes or linked worktrees at once, and `sled` takes an exclusive process lock on its directory and has no recent stable releases. Placing the database under `git rev-parse --git-common-dir` lets linked worktrees share cached decisions without polluting the working tree. Each entry stores only a versioned SHA-256 key and the resulting decision (never source code, and never answers produced from trimmed hoisted signatures) and expires 30 days after creation so moving model aliases such as `jev-latest` periodically refresh.
